# Student Management System

A Django-based Student Management System with authentication, role-based permissions, dashboard, search, pagination, photo upload, and CRUD operations.

## Features

- User Authentication
- Student CRUD
- Search
- Pagination
- Dashboard
- Photo Upload
- User Roles
- Bootstrap 5

## Technologies

- Python
- Django
- SQLite
- Bootstrap 5

## Installation

```bash
git clone https://github.com/IASvishal/StudentManagement.git
cd StudentManagement
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
